# Agent Behavior Teardown

**Status:** Completed analysis | **Area:** Agentic AI

## Problem
Conversational interfaces can appear more autonomous than the actions they actually perform.

## Approach
A structured assessment of Copilot in Teams using happy-path, missing-information, ambiguity, high-stakes and probe scenarios.

## Product decisions
- Judge observable tool use and execution rather than the agent label.
- Probe escalation and uncertainty handling.
- Translate failure modes into product and guardrail improvements.
