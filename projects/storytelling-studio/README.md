# AI Storytelling Studio

**Status:** Local prototype | **Area:** Generative AI

## Problem
Creating a narrated short requires coordinating scripts, scenes, images, voice and rendering.

## Approach
A local creative workflow with human review between story development and generated media.

## Product decisions
- Structured the work into approved milestones rather than one opaque generation.
- Benchmarked image generation against an Apple M1 memory and latency budget.
- Kept motion generation behind an approval step.

## Evidence and limits
Project discussions record local backend/frontend tests and a rendered Midnight Line narrated slideshow. The Runway workflow was implemented but disabled; paid motion generation is not evidenced.
